1Starting the app

Double-click SpaceAnalyzer.exe. When Windows asks for permission, click Yes, the app needs administrator rights so it can read every folder and clean system locations. The window opens full screen and immediately scans the computer you are on.

To scan other computers on your network, you only need administrator rights on those machines; everything else is done from inside the app.

2The main window

Across the top are the action buttons: Scan drives (or press F5), a Fast scan switch, Stop, Refresh drive list, Recycle Bin, Network VMs, and Schedule.

Below those is the machine bar (see the next section), then the drive tiles showing each drive's free space and how full it is (the bar turns orange above 75% and red above 90%). Tick drives to choose what to scan. Under the tiles are the tabs: Cleanup advisor, Biggest folders, Biggest files, File types, and By user. The status line at the bottom shows what the app is doing and links to the deletion log and debug log.

SEM sites and plants

After a machine scan finishes, Space Analyzer searches its fixed drives for smartplantv4.ini files and enables SEM plants. It searches only the machine selected in the machine bar: your own computer or the VM tab you scanned. The search skips protected Windows folders and directory links.

Open SEM plants to see sites grouped by site, with plants sorted by folder space, database space, or name. Folder space comes from the machine scan. Database space comes from the SEM plant's schema or database files. These two figures are shown separately because database files already occupy disk space. Shared Oracle schemas, shared tablespaces, and SQL Server databases used by multiple plants are called out separately and excluded from individual plant totals when their ownership is shared or unclear.

To remove a plant, select it and choose Review and delete plant. Read the fresh list of folders and database items, then type the exact confirmation phrase. Plant deletion is permanent. A site-wide delete is not offered here. If the SEM database or site file cannot be read, the app shows an error row instead of enabling deletion. If only a size query fails, that size appears as unavailable and the warning is included in the site details.

The combined build needs SpaceAnalyzer.exe and Delete Plant Utility CLI.exe in the same folder. For a VM, the app copies the helper to that VM while it reads the selected site's data. Your account needs the same remote access rights required for the normal VM scan.

3Machines and tabs

Everything on screen always belongs to one machine, named in the "Viewing:" bar. Your own computer is the first tab. Each VM you scan becomes its own tab. Click a tab to switch, and the drive tiles, folders, files, types, and advisor all change to that machine. Close a VM tab with the small x. Your computer's data and a VM's data are never mixed.

4Cleanup advisor

This tab opens first and shows how much space can be freed on the machine you are viewing, grouped into three kinds.

GroupMeaning
SafeTicked automatically. Caches and leftovers that Windows and programs rebuild as needed: temporary files, Windows Update downloads, delivery optimization cache, error reports, browser caches, and the Recycle Bin.
Check firstNot ticked. Usually fine but worth a look: crash dumps, old IIS logs, old downloads, old .bak backups, the hibernation file, and Windows component cleanup.
Leave aloneShown for information only, never delete by hand: Windows Installer, WinSxS, and the page file.

Each item shows its size and a Review files link. Click an item to see its files and tick exactly which to delete. Tick whole items with the box on the left, then click Clean selected.

Cleanup advisor deletes permanently (caches do not go to the Recycle Bin). The confirmation says so before anything happens. Files in use are skipped automatically.

5Biggest folders

Folders in the current location, biggest first, with a share bar, next to a space map where each box is sized by how much space it uses. Double-click a folder (or click its box) to go inside; Up one level or Backspace to go back. Double-click Files directly in this folder to list those files and choose any to delete. Use Open in Explorer or Move to Recycle Bin on a selection.

6Biggest files

The 500 largest files with type, date, and folder, plus a chart of the top 15. Select files (Ctrl or Shift+click), then Move to Recycle Bin or Show in Explorer. Export report saves a CSV you can open in Excel.

7File types

Which kinds of files use the most space (.log, .bak, .iso, and so on), with a donut chart. Tip: type a type like .log in the filter box, then open Biggest files to see exactly which files they are.

8By user

Finds which people own the most old data, so you know who to ask before cleaning. Click Analyze users after a scan. It combines two sources:

  • Windows profiles under Users\ (system profiles like Public are skipped).
  • Team folders named by short name. Click Team folders..., list the parent folders where each person has their own sub-folder (for example D:\Projects), save, then analyze. Each immediate sub-folder is treated as a person.

The table ranks people by old-data size, with total size, old-file count, and where their folders are. Set what counts as "old" (default 180 days).

9Network VMs

Click Network VMs to work with other computers in your domain. The window opens your saved list and automatically checks which are reachable: each shows Ready to scan, Offline, Online, access denied (you are not an admin there), or Online, no shares.

  • Add VM by name or Import list to build your list; it is saved automatically. Remove selected, Edit saved list, and Reload saved list manage it.
  • Tick one or more Ready to scan VMs and click Scan selected VM(s). Each is scanned on the VM itself (fast) and opens as its own tab. Several VMs are scanned one after another automatically.

How a VM scan works

Space Analyzer copies itself to the VM, runs the scan there using Windows' built-in management service, and brings the small result back. You need administrator rights on the VM, and its firewall must allow WMI ("Windows Management Instrumentation (WMI-In)"). On a VM tab you can review folders, files, types, the advisor, and delete or clean, just like on your own computer.

A VM has no Recycle Bin reachable across the network, so deletes on a VM are permanent. The app confirms first and never touches protected Windows locations.

10Scheduled maintenance

Click Schedule to have the scan run by itself on a timetable and email folder owners their old files.

  1. Tick the VMs to include (from your saved Network VMs list).
  2. Choose the days and time, and what counts as an old file.
  3. Click Create / update schedule. Windows will run Space Analyzer quietly at those times.

For emails to be sent, two files next to the app must be filled in: OwnerMap.csv (which folder belongs to which person's email) and EmailSettings.ini (your mail server). Each run writes SpaceAnalyzer_Schedule.log so you can see what happened. Use Remove schedule to stop it.

The scheduled run only reads and emails; it does not delete anything. People decide what to remove from the list they receive.

11Recycle Bin

Click Recycle Bin to see everything in the Recycle Bin on every drive, with each item's original location, size, and the date deleted. Tick items and choose Restore ticked, Delete ticked, or Empty whole bin. Remember: space is only freed once items are deleted from the bin.

13How it keeps you safe

  • Nothing is deleted without a confirmation, with the default answer set to No.
  • Windows system locations (Windows, Program Files, the page file, user-profile roots, and similar) are protected and cannot be deleted.
  • On your own machine, files and folders go to the Recycle Bin first. Advisor cleanups and all VM deletes are permanent.
  • Every deletion is written to SpaceAnalyzer_Log.csv next to the app: time, user, machine, path, size, and result.

14Problems and questions

A VM shows "access denied" or "offline"

"Access denied" means your account is not an administrator on that VM. "Offline" means it is switched off or its firewall is blocking file sharing or WMI. For scanning a VM, allow the firewall rule "Windows Management Instrumentation (WMI-In)".

I deleted files but free space didn't change

Files removed on your own machine went to the Recycle Bin, open the Recycle Bin screen and empty it. Advisor and VM deletes are already permanent.

Some files were skipped

They were in use by a running program. Close it, or clean during a maintenance window, and try again.

Scheduled emails aren't arriving

Check EmailSettings.ini (mail server and From address) and OwnerMap.csv (folders and owner emails) next to the app, and read SpaceAnalyzer_Schedule.log for what happened.
